  • 조건 && 구문 : A,B 조건 모두 참인 경우
  • && 앞의 조건이 true인 경우
  • && 앞의 조건이 false인 경우
  • 조건 || 구문 : 두 조건 중 하나만 참인 경우

  • || 앞 조건이 false인 경우 -> 뒤 구문 실행 ( 내용 반환 )
